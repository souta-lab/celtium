# Celtium 0.2.0 — GL-less surface, measured

*Released 2026-11-04 · tag [`v0.2.0`](https://github.com/souta-lab/celtium/releases/tag/v0.2.0) · previous [`v0.1.4-alpha-rc.26`](https://github.com/souta-lab/celtium/releases/tag/v0.1.4-alpha-rc.26)*

**393 commits** since 0.1.4-alpha-rc.26 (fix 177 / perf 125 / feat 30 / docs 32 / chore 10 / measure 6 /
refactor 5 / test 3 / revert 1 / profile 1 / glow 1). This release hardens the GL-less renderer's
"it starts and draws" foundation with measurements, CPU verification and scene comparisons.

> **The FPS goal is not met**: the paired KPI against Celeritas is **1.189** (`NOT_MET`). Rendering
> fidelity and error-free operation moved a long way, but frame time still loses. See "Performance"
> and "Known issues".

---

## Highlights

- **The build works again.** Upstream compile breaks are repaired (`RenderSection`'s metrics accessors,
  two misplaced mixin annotations, and a missing Lombok version in `build-1122` that left annotation
  processing off), and `packageJar` / `validationRemapJar` succeed.
- **A CPU verifier for transformer-generated bytecode.** It loads 241 real LWJGL declarations and 87 real
  GL classes, and it found **four runtime VerifyErrors**, one of which made GL20C itself unloadable and
  blocked the shader path at startup.
- **Indexed drawing.** Client and VBO vertices, client index arrays, baseVertex, multi-draw, the
  instance=1 derived forms, 12/16/20/24/32-byte layouts and the 32-byte repack.
- **Legacy immediate mode** (glBegin/glEnd) draws by default. Title screen, menu background and pack-menu
  art reach the frame, confirmed by scenes.
- **Creative screen** scene and icons, tooltip motion frames, and the model replay hot path are measured
  and fixed.
- **Large GL-surface repair**: reconnected unreachable display-list / pixelStore / buffer / texture / FBO /
  shader getters; fixed pname mix-ups, uninitialised outputs, fixed-width write overruns, per-VAO
  attributes, push/pop attribute stacks, light/fog/material state and binding queries.
- **Performance measurement**: same-JAR, same-leg A/B, a control arm that cancels machine drift, JFR
  profiles, and window/group/accept-path breakdowns.

## Breaking changes and migration

- **Version**: `0.2.0`. Explicit release builds via `-Pceltium_release_version` work as before.
- **Build environment**: Gradle must run on **JDK 25** (RetroFuturaGradle 2.0.4 requirement).
  `JAVA_HOME=/usr/lib/jvm/java-25-openjdk-amd64 scripts/build.sh`.
  `build-1122/gradle.properties` must carry `lombok_version`; without it `@Getter` is not generated.
- **glstub scope is unchanged**: it applies only to mods that call GL directly.
- **Configuration**: existing `-Dceltium.*` switches are kept. New experimental switches default to the
  safe side (for example `-Dceltium.vulkan.mainClearInQueue` defaults off and
  `-Dceltium.vulkan.replayValueVersions` defaults on).
- **Artifact**: `celtium-forge-mc1.12.2-0.2.0.jar`
  (sha256 `bf1193b6ba21dc51cd36a5b013607dd58a9ef8bcbc516ca8f24b0c247e9cccee`).

## Added

### Draw paths
- Indexed drawing: `glDrawElements` / `glDrawRangeElements` / `glDrawElementsBaseVertex` /
  `glDrawElementsInstanced` / `glDrawElementsInstancedBaseVertex` /
  `glDrawElementsInstancedBaseInstance` / `glDrawElementsInstancedBaseVertexBaseInstance`
  (instance=1 forwards to the uninstanced draw).
- Multi-draw: `glMultiDrawArrays` / `glMultiDrawElements` (each sub-draw replays through the decoded path).
- Legacy immediate mode: every glBegin/glEnd vertex spelling (float/double/int/short/byte), glRect*,
  multi-texture coordinates, and every draw mode.
- Topologies: lines / line strip / line loop / triangle strip / quad strip / polygon are accepted and
  converted.
- Attributes: `glVertexAttribPointer` / `glVertexAttribIPointer` (index 0), normalized/integer flags,
  per-VAO attribute records, and `glPushClientAttrib` / `glPopClientAttrib` / `glPushAttrib` /
  `glPopAttrib` restoration.

### GL surface
- Display lists: `glNewList` / `glEndList` / `glCallList` / `glCallLists` / `glListBase` /
  `glDeleteLists` / `glIsList`.
- pixelStore: UNPACK/PACK recording, queries, and use by the upload conversion.
- Buffers: storage / sub-data / copy / readback / map (including DSA) / clear (zero fill) / binding
  queries.
- Textures: storage (including DSA) / sub-image (DSA) / parameters (f/iv/fv/Iiv/Iuiv, DSA) /
  border colour / level parameters (DSA) / zeroed image readback.
- Framebuffers: EXT/ARB spellings, Named attachment/state/parameter forms, renderbuffer extents.
- Shaders: info logs (including ARB), active uniforms/attribs, program binary, precision, resource
  queries, compile/link status, and not-found lookups (-1).
- Sync: `glGetSynciv` reports SIGNALED; query results report visible (1).
- Debug: empty labels from `glGetObjectLabel` / `glGetObjectPtrLabel`.

### Scenes and verification
- Scenes and reference comparisons for menu/title/pack menu, creative screen, tooltip motion, models,
  sky, clouds, fog and the glow outline.
- The route verifier (`scripts/cpu-contract/transformer-route-verify.sh`) joins the CPU contract.
- A KPI control arm that interleaves candidate / Celeritas / a past build inside one leg.

## Changed / Improved

### Rendering fidelity
- Title screen, menu background and pack-menu art reach the frame (confirmed by scenes).
- Creative-screen missing icons (an empty item-plan cache) are fixed.
- Tooltips: one tooltip per frame while moving; lost/ghosted tooltips while a mod framebuffer is bound
  are fixed.
- Models and custom rendering: shared mirror supply, attribute 0 description, per-VAO pointers, indexed
  paths.
- Sky/cloud/fog/light/depth/blend/scissor/polygon-offset state is reflected consistently.
- Translucent terrain back-face culling, alpha test kept during combine, and stained-glass flicker are
  fixed.

### State and queries
- pname mix-ups fixed (SKIP_PIXELS/ROWS, SPOT_CUTOFF, VIEWPORT_DIMS, SHADE_MODEL and others).
- Uninitialised outputs cleared (sampler/renderbuffer/multisample/uniform/object label and others).
- Fixed-width write overruns fixed (light/material component counts, one-byte booleans).
- Binding queries (element/pixel/uniform/copy buffers, texture 1D/3D/cube, renderbuffer).
- Capability values made consistent (texture units, anisotropy, attachment/draw buffers, uniform
  vectors, stack depth).

### Performance
- Model replay: input cache, value versions, shared light payload, shared matrices/colour/scissor.
- Grouping: state keys, fog/scissor/polygon-offset capture, window measurement.
- Clears: flush-site measurement, main-FBO clear on the queue (default off, with a refusal census).
- Hot paths: single lookups, constant property reads, fewer allocations.
- Fonts: scratch matrix save in the batch, narrowed colour witness.

## Fixed — main items

- **Startup/build**: missing `RenderSection` metrics accessors, two misplaced `@Inject`, a duplicate
  `@Shadow`, and Lombok annotation processing not running.
- **Runtime crashes**: `glClearBufferSubData` slots, `glPushClientAttrib` missing argument,
  `glDrawElementsInstancedBaseInstance` slots, and `nglGetShaderInfoLog` slots (GL20C unloadable).
- **Textures**: missing mirror supply, PBO uploads, DSA uploads, sub-image patches, name reuse after
  delete, sampler inference (wrap/filter).
- **FBOs**: attachment records, EXT/ARB/Named spellings, delete cleanup, readback routing.
- **State**: raw depth/alpha/lighting enables, push/pop, VAO attributes, light/fog/material, pixel
  store, buffer bindings.
- **Queries**: uninitialised outputs, pname mix-ups, wrong widths, not-found answering 0 (now -1).
- **Drawing**: index layout/offset/repack, client memory, instance=1, lines/strips/polygons, attribute 0.
- **GUI**: menu background, creative tabs, tooltips, HUD colour/depth.

## Performance

### Paired KPI against Celeritas (**modpack environment**, AMD RX 6400 / RADV NAVI24, 1280×720, 3 pairs)

**Measurement environment (important)**: the run uses the same **Cleanroom Relauncher modpack instance**
as the tester, `celtium-world-accept` (**192 mods**, save `qmagnet`), not a bare client. Scene `world`,
pose `x=217.5 y=48 z=217.5 yaw=180 pitch=10`, `guiScale=3`, `renderDistance=12`, `maxFps=260`, vsync off,
1280×720. Each leg runs 240 s; the warm window is world ticks 400–600 (hold 620).
KPI legs run **validation off** to remove the measurement tax
(`-Dceltium.vulkan.validation=false`, `presentReadback=false`, `presentedDumpEvery=0`) and interleave with
Celeritas 2.5.0-dev (sha256 `567dcf8a…`) under the same scene and JAR conditions. The control arm is the
round-58 build (`de8ed2e7…`). **Validation-zero evidence comes from separate validation-on legs**
(`r64c-carry` and others); the KPI legs' `validationMessageCount=0` is not counted as clean-validation
evidence because validation is off there.

| rep | Celtium p50 | Celeritas p50 | ratio | vs past build |
|---|---|---|---|---|
| 1 | 2.742 ms | 2.332 ms | 1.176 | 0.985 |
| 2 | 2.869 ms | 2.413 ms | 1.189 | 1.063 |
| 3 (load contamination) | 3.620 ms | 2.311 ms | 1.566 | 1.380 |
| **median** | | | **1.189** | **1.063** |

- `goalCondition=NOT_MET`. The two clean reps are 1.176 / 1.189; against the round-58 build they are
  −1.5% / +6.3%.
- Rep 3 has `finalLoadAverage` 0.96 → 3.98; the same contamination shape appeared in round 63.
- **Frame split (shipping code, AMD)**: frame 1322 µs = world 861 + gui 421 + hand 50.
  **85% is Celtium's immediate path** (accept 161 offers × 4024 ns = 648 µs + flush 392 + guiFlush 81).
  Units are offer 160.8 / group 131.9 / window 23.4.
- **Windows open on framebuffer bind** (`flushSiteCounts=[bind-framebuffer=792]`, 65% of
  `flushReasons`). The clear-origin hypothesis is rejected.
- **Remaining structural levers**: a per-bind census of whether the frame image is actually sampled and
  removal of unnecessary flushes; bracketing the unmeasured accept-path stretch (about 470 lines from
  offPreflight to offAppend); bindless immediate textures; a second open group for opaque,
  depth-writing, unblended groups.
- **Rejected** (do not retry): sticky pass merging (2.85 → 11.47 ms), font-run matrix baking (94 → 8
  runs), clear-origin flush reduction (windows/frame unchanged), the stateKey format factor (hit rate
  stays 21.9%).

## Known issues

- **FPS is 1.189 against Celeritas and not met.** The accept path and windows remain. Intel's p99
  (1.048) is also unresolved.
- **Menu/tooltip/creative tabs** are confirmed by scenes but need a re-check in the tester environment.
- **Not implemented**: cube maps / 3D textures / MSAA / compute / blit / copyImage / some DSA /
  stencil (ModularUI's Stencil#reset uses mask 0x400 and is unimplemented).
- **Real legs depend on the environment**: they rely on the verification harness's Prism instance
  layout. The distributed JAR needs a separate tester check.
- **Shadows/shader packs**: a separate addon built from the Demonica fork; not part of core.

## Install

1. Prepare a Cleanroom Relauncher setup (Cleanroom 0.7.12-alpha / LWJGL 3.4.3 / game JVM Java 27).
2. Put `celtium-forge-mc1.12.2-0.2.0.jar` into `mods/`.
3. Start the game, enter a world, and check GUI/menu/creative/tooltips.
4. For bug reports, attach `logs/latest.log`, whether `-Dceltium.vulkan.validation=true` was set, the
   GPU, the scene, and the JAR sha256.
