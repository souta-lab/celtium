# Celtium 0.1.0-alpha

対象: **Minecraft 1.12.2 / CleanroomMC 0.7.11-alpha / SDL3・LWJGL 3.4.3 / Java 27**。
0.6.13-alpha（GLFW / LWJGL 3.4.1）は起動時に明示拒否します。

jar: `celtium-forge-mc1.12.2-0.1.0-alpha.jar`（sha256 `4d228696f0ec1827eae13bf0c6f5062f13185623e456b0cd72946e96903d15be`、
commit `d34676512`）。world 受入 leg は AMD RX 6400 / Intel UHD 630 とも PASSED・Vulkan validation 0。

## 性能

- **移動中の体感 lag を減らしました。** 地形の occlusion 探索（どの section が見えるか）を毎フレーム client thread で
  実行していたのを、専用の探索 thread に移しました。移動中は client thread の約 28% がこの探索でした。
  AMD RX 6400 の飛行リプレイで中央値フレーム時間 1.03–1.34 → 0.74–0.89 ms。
  オプションの「Async occlusion」が **Off（NONE）以外なら有効**です（本体に影 pass が無いため、
  既定値 Only Shadows は今まで「何も非同期にしない」と同じでした）。
- 静止した計測 scene（Xaero's Minimap 入り、1280×720、3 対の中央値）での Celeritas 2.5.0-dev 比:
  **AMD 0.992x（同等）**、**Intel 1.205x（遅い）**。Intel はこの scene で GPU 律速で、差はまだ残っています。

![benchmark](https://raw.githubusercontent.com/souta-lab/celtium/main/docs/img/benchmark-light.svg)

## 修正・内部

- Vulkan validation `VUID-vkCmdDrawIndexedIndirect-None-08600` の原因を特定（描画順で別 pipeline が bind されたまま）。
  該当の実験的な pass 統合は速くならなかったため入れていません。
- 検証 fixture に飛行リプレイ（`-Dceltium.validation.flightBlocksPerSecond`）と、移動中のスパイクを名指しする
  `warmSpikes` を追加。

## 既知の問題

- Intel UHD 630 では Celeritas より約 20% 遅い。
- 移動中の 16 ms 超のフレームは Celeritas より多い（Celeritas 0 枚に対し数枚）。
- シェーダーパックと影は本体では非対応（Demonica fork の別 addon で進行中）。
- RLCraft 2.9.3 は Celtium の有無にかかわらず Cleanroom で起動しないため対象外。巨大 pack の検証は E2E-E に切り替えます。
