# Celtium 0.1.2-alpha — Vulkan bindings packaging hotfix

**2026-10-29** · Minecraft 1.12.2 · CleanroomMC 0.7.x (SDL 3 / LWJGL 3.4.3)

## Fixed

- **Black screen at startup on regular Prism Launcher installations.** Celtium's GL-less window and OpenGL stubs were enabled, but the renderer could not initialize because `org.lwjgl.vulkan` was absent from the runtime classpath. Logs repeatedly reported `CELTIUM_WINDOW_RENDERER created=false ... reasons=[Vulkan bindings are not available on this classpath]`.
- The distributable JAR now **embeds LWJGL's `lwjgl-vulkan` 3.4.3 Java bindings**, which were previously `compileOnly` and injected into the classpath by our test harness. The LWJGL core, SDL/GLFW and native platform libraries are still provided by Cleanroom, not bundled or replaced.
- Installing the one Celtium mod JAR into a compatible Cleanroom 0.7 instance should no longer require manually modifying Prism's Java classpath to add `lwjgl-vulkan`.

## Verification and limitations

- The packaged JAR builds successfully and contains `org/lwjgl/vulkan/VK.class` and `org/lwjgl/vulkan/VkDebugUtilsMessengerCallbackEXTI.class`.
- This addresses the **specific missing-Vulkan-binding failure** found in [the first external user log](https://mclo.gs/c9kRfFD). The reported Windows 11 / RTX 3070 setup has **not yet been retested with the hotfix**, so full startup and picture correctness there remain unverified.
- Only Cleanroom 0.7's SDL 3/LWJGL 3.4.3 runtime is supported. Stock Forge, LWJGL 2, older Cleanroom 0.6 builds, and incompatible rendering mods remain unsupported. Use Java 27 as in the tested configuration.
- The Vulkan native loader/driver and supported Vulkan 1.2+ device remain necessary; including the Java bindings does not supply a GPU driver or fix unrelated issues.

The last measured gameplay, image-quality and performance results belong to [0.1.1-alpha](0.1.1-alpha.md), not this hotfix.
