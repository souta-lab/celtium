# Celtium 0.1.1-alpha

対象: **Minecraft 1.12.2 / CleanroomMC 0.7.11-alpha / SDL3・LWJGL 3.4.3 / Java 27**。
0.6.13-alpha（GLFW / LWJGL 3.4.1）は起動時に明示拒否します。GL-less（Vulkanのみ）が既定で、JVM引数は不要です。

## 修正

- **色付きガラスのちらつき**: 半透明の地形（色付きガラス・氷・スライム）が裏面まで描かれ、2層目として合成されていました。
  視点で重なり順が変わるのがちらつきの正体で、色も参照より 20–25 段階暗くなっていました。vanilla と同じく裏面を描きません。
- **一人称の手が明るすぎる**: 照明つきのモデルが固定機能 GL のように光量を [0,1] に丸めておらず、手が約 1.16 倍明るく描かれていました。
- **ブロックの陰影**: ブロックを Forge のブロックモデル経路でメッシュ化します（upstream Celeritas と同じ）。
  一部の面の明るさが ±10–22% 違っていました。`-Dceleritas.useVintageFastBlockRenderer=true` で以前の経路に戻せます。
- **fps 上限が効かない**: ワールド内で fps 上限を設定すると、値に関係なく画面のリフレッシュレートで制限されていました
  （60 Hz で上限 120 → 60 fps）。設定どおりに制限します。
- **ワールド入場時の確保**: 使わない vanilla の chunk バッファ（約 600 MB）を入場時に確保・ゼロ埋めしていました。
- リサイズ時のロード画面の引き継ぎが、GL-less を明示指定したときだけ働いていたのを既定でも働くようにしました。
- 毎フレームのスタック採取（`gluPerspective` と DynamicTexture の upload）を止めました。
- **JourneyMap のミニマップに地図が出ない**: 生の GL（`glTexSubImage2D`）で後から書き込まれたテクスチャが Vulkan 側に
  反映されていませんでした。JourneyMap は空の 512×512 を作ってから 16×16 ずつ埋めるため、地図タイルが透明のままでした。
- **atlas 読み込みのエラー**: 独自ローダーを持つ sprite（OpenBlocks の canvas など）まで画像ファイルを読みに行き、
  256 件の「Using missing texture」を出して拒否していました。Tinkers' Construct の色付きパーツが依存先の読み込み完了前に
  作られて atlas ごと落ちる問題も、依存先を待つことで直しました。読めない画像は 1 件ずつのスタックトレースではなく
  FML のまとめ（vanilla + VintageFix と同じ）に報告します。
- GL-less で意味のない警告（タイマークエリ、GLSL）と、一度も適用されていなかった `ExplicitGcMixin` の警告を出さなくしました。

## 性能（Celeritas 2.5.0-dev 比、0.1.1-alpha の jar、Xaero なし、qmagnet、1280×720、vsync off、warm tick 400–600、3 対）

![frame time](../img/benchmark-light.svg)

| GPU | p50 | p95 | p99 |
| --- | --- | --- | --- |
| AMD RX 6400 | **0.59x**（0.63 vs 1.06 ms） | **0.60x** | **0.83x**（9 つの比がすべて 1 未満） |
| Intel UHD 630 | 0.90x（1.58 vs 1.77 ms） | 0.87x | **1.05x（遅い）** |

0.1.0-alpha は同種の計測（Xaero あり）で p50 が AMD 0.99x・Intel 1.21x でした。

## 画質（Celeritas 2.5.0-dev と画素比較、[証拠](../evidence/image-quality-2026-10-28.md)）

設定画面は画素一致、メニューはスプラッシュ文言とパノラマ位相のみの差、ゲーム画面は 16 段階超の差が約 1%
（アニメーション位相と参照側の壁の陰影）、ロード画面は vanilla の描画手順どおり。

## 既知の問題

- Intel UHD 630 の p99 は Celeritas より約 5% 遅い（client tick が約 10–15% 遅い。[証拠](../evidence/intel-p99-2026-10-28.md)）。
- エンティティ・ブロックエンティティは GL 状態呼び出しの列を経て native 描画に届く（GL ドライバには届かない）。
- シェーダーパックと影は本体では非対応（Demonica fork の別 addon）。
- 起動時に停止する競合 mod: Custom Loading Screen、SmoothFont、Gnetum、Nothirium、Naughthirium。
