# Celtium 0.2.0 — GL-less surface, measured

0.1.4-alpha-rc.26 からの 393 commits。GL-less レンダラの「起動して絵が出る」土台を、
実測とCPU検証で固めたリリース。FPS の対 Celeritas 目標は未達（paired KPI 1.189）。

## ハイライト

- **ビルドが通る状態に戻した**。上流由来の未コンパイル（`RenderSection` の metrics アクセサ、
  mixin の注釈位置、`build-1122` に Lombok のバージョンが無く annotation processing が動いていなかった）を修復。
- **transformer 生成バイトコードの CPU 検証器**を追加（`scripts/cpu-contract/transformer-route-verify.sh`）。
  実 LWJGL 宣言 241 件と実 GL クラス 87 個をロード検証し、実行時 VerifyError を 4 件修正
  （`glClearBufferSubData` / `glPushClientAttrib` / `glDrawElementsInstancedBaseInstance` /
  `nglGetShaderInfoLog`。最後は GL20C 自体がロード不能だった）。
- **インデックス描画**を実装: クライアント/VBO 頂点、クライアントインデックス、baseVertex、
  multi-draw、instance=1 の派生形、12/16/20/24/32 バイトのレイアウトと 32 バイトの再パック。
- **レガシー即時モード**（glBegin/glEnd）を既定で描画。タイトル画面・メニュー背景・
  パックメニューのアートがフレームに載ることをシーンで確認。
- **クリエイティブ画面**のシーンとアイコン、ツールチップの移動フレーム、モデルリプレイの
  ホットパスを計測・修正。
- **GL 表面の大規模修復**: 到達不能だった display list / pixelStore / buffer / texture / FBO /
  shader getter 群の再接続、pname 取り違え、未初期化出力、固定幅書き込みのオーバーラン、
  VAO 別属性、push/pop 属性スタック、ライト/フォグ/マテリアル、バインディングクエリ。
- **性能**: モデルリプレイの入力キャッシュと値バージョン化、グループ化/ウィンドウの計測、
  クリア順序の整理、ホットパスの単一参照化。同一 JAR・同一 leg 内 A/B を基本にした。

## 変更点（0.1.4-alpha-rc.26 → 0.2.0）

### 起動・ビルド・検証
- `common` の `RenderSection` に metrics のビルド時間アクセサを追加（上流の未コンパイル修復）。
- `@Inject` がフィールドの上に置かれていた 2 箇所、`@Shadow` の二重付与 1 箇所を修正。
- `build-1122/gradle.properties` に `lombok_version` を追加（`@Getter` が生成されていなかった）。
- ルート検証器を追加し、CPU 契約チェックの一覧に登録。probe 241 / 実クラス 87 を検証。
- `scripts/tests` 177 tests、`celtium-vulkan` 422 tests、`check_agent_docs`、`instrument-index` を維持。

### 描画忠実度
- レガシー即時モード: glBegin/glEnd の全頂点綴り・描画モード、glRect*、マルチテクスチャ座標。
- タイトル画面/メニュー背景/パックメニューのアートをフレームへ（シーンと参照比較を追加）。
- クリエイティブ画面のシーン、アイコン欠落の原因（空の item plan キャッシュ）を修正。
- ツールチップ: 移動フレームで 1 フレーム 1 ツールチップ、モッド FBO バインド中の取りこぼし/残像を修正。
- モデル/カスタム描画: ミラー供給の共通化、属性 0 の記述、VAO 別ポインタ、インデックス経路。
- 空/雲/フォグ/ライト/深度/ブレンド/シザー/ポリゴンオフセットの状態反映を整理。
- 描画トポロジ: lines / strips / quad-strip / polygon の受理と三角形変換。

### GL-less GL 表面
- display list: glNewList/glEndList/glCallList/glCallLists/glListBase/glDeleteLists/glIsList のルート化。
- pixelStore: UNPACK/PACK の記録とクエリ、アップロード変換への反映。
- buffer: storage / sub-data / copy / readback / map（DSA 含む）/ clear（零埋め）/ binding クエリ。
- texture: storage（DSA 含む）/ sub-image（DSA）/ parameter（f/iv/fv/Iiv/Iuiv、DSA）/ border colour /
  level parameter（DSA）/ image readback のゼロ化。
- framebuffer: EXT/ARB 綴り、Named 形式のアタッチメント/状態/パラメータ、renderbuffer の extent。
- shader: info-log（ARB 含む）、active uniform/attrib、program binary、precision、resource 系、
  compile/link status、not-found ルックアップ（-1）。
- 同期: glGetSynciv は SIGNALED、クエリ結果は可視（1）。
- 属性: glVertexAttribPointer/IPointer、normalized/integer フラグ、VAO 別記録、push/pop 復元。

### 状態・クエリ
- pname の取り違え（SKIP_PIXELS/ROWS、SPOT_CUTOFF、VIEWPORT_DIMS、SHADE_MODEL 等）を修正。
- 未初期化出力の一掃（sampler/renderbuffer/multisample/uniform/object label 等）。
- 固定幅書き込みのオーバーラン修正（light/material の成分数、boolean の 1 バイト）。
- バインディングクエリ（element/pixel/uniform/copy buffer、texture 1D/3D/cube、renderbuffer）。
- 能力値の整合（texture units、anisotropy、attachment/draw buffers、uniform vectors、stack depth）。

### パフォーマンス
- モデルリプレイ: 入力キャッシュ、値バージョン化、ライトペイロードの共有、行列/色/シザーの共有。
- グループ化: 状態キー、フォグ/シザー/ポリゴンオフセットのキャプチャ、ウィンドウ計測。
- クリア: 順序 flush のサイト計測、メイン FBO クリアのキュー搭載（既定 off、拒否 census 付き）。
- ホットパス: 単一参照化、プロパティ読みの定数化、アロケーション削減。
- KPI: 同一 JAR・同一 leg 内 A/B、control arm でマシンドリフトを相殺。

### 既知の制約
- **FPS は Celeritas 比 1.189（NOT_MET）**。accept path（648 µs/2.0 ms）とウィンドウ（bind 起点）が残。
- メニュー/ツールチップ/クリエイティブタブの一部はシーンで確認済みだが、テスター環境での再確認が必要。
- 未実装: cube map / 3D texture / MSAA / compute / blit / copyImage / 一部の DSA。
- 実機 leg はこの環境のハーネス前提（インスタンス）に依存。テスター配布 JAR は別途。
