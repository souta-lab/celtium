# Celtium 0.2.0 — GL-less surface, measured

*Released 2026-11-04 · tag [`v0.2.0`](https://github.com/souta-lab/celtium/releases/tag/v0.2.0) · previous [`v0.1.4-alpha-rc.26`](https://github.com/souta-lab/celtium/releases/tag/v0.1.4-alpha-rc.26)*

0.1.4-alpha-rc.26 からの **393 commits**（fix 177 / perf 125 / feat 30 / docs 32 / chore 10 / measure 6 /
refactor 5 / test 3 / revert 1 / profile 1 / glow 1）。GL-less レンダラの「起動して絵が出る」土台を、
実測・CPU検証・シーン比較で固めたリリースです。

> **FPS 目標は未達**: Celeritas との paired KPI は **1.189**（`NOT_MET`）。描画忠実度とエラーゼロは
> 大きく前進しましたが、フレーム時間ではまだ負けています。詳細は「性能」と「既知の課題」。

## ハイライト

- **ビルドが通る状態に戻した**。上流由来の未コンパイル（`RenderSection` の metrics アクセサ、
  mixin の注釈位置、`build-1122` に Lombok のバージョンが無く annotation processing が動いていなかった）
  を修復し、`packageJar` / `validationRemapJar` が成功する。
- **transformer 生成バイトコードの CPU 検証器**を追加。実 LWJGL 宣言 241 件と実 GL クラス 87 個を
  ロード検証し、**実行時 VerifyError を 4 件修正**。うち 1 件は GL20C 自体がロード不能で、
  シェーダ経路が起動できない状態だった。
- **インデックス描画**を実装。クライアント/VBO 頂点、クライアントインデックス、baseVertex、
  multi-draw、instance=1 の派生形、12/16/20/24/32 バイトのレイアウトと 32 バイトの再パック。
- **レガシー即時モード**（glBegin/glEnd）を既定で描画。タイトル画面・メニュー背景・パックメニューの
  アートがフレームに載ることをシーンで確認。
- **クリエイティブ画面**のシーンとアイコン、ツールチップの移動フレーム、モデルリプレイのホットパスを
  計測・修正。
- **GL 表面の大規模修復**: 到達不能だった display list / pixelStore / buffer / texture / FBO /
  shader getter 群の再接続、pname 取り違え、未初期化出力、固定幅書き込みのオーバーラン、
  VAO 別属性、push/pop 属性スタック、ライト/フォグ/マテリアル、バインディングクエリ。
- **性能計測基盤**: 同一 JAR・同一 leg 内 A/B、control arm によるマシンドリフト相殺、
  JFR プロファイル、ウィンドウ/グループ/受理経路の内訳。

## 追加（Added）

### 描画経路
- インデックス描画: `glDrawElements` / `glDrawRangeElements` / `glDrawElementsBaseVertex` /
  `glDrawElementsInstanced` / `glDrawElementsInstancedBaseVertex` / `glDrawElementsInstancedBaseInstance` /
  `glDrawElementsInstancedBaseVertexBaseInstance`（instance=1 は通常描画へ転送）。
- マルチドロー: `glMultiDrawArrays` / `glMultiDrawElements`（サブ描画をデコード経路で再生）。
- レガシー即時モード: glBegin/glEnd の全頂点綴り（float/double/int/short/byte）、glRect*、
  マルチテクスチャ座標、全描画モード。
- 描画トポロジ: lines / line strip / line loop / triangle strip / quad strip / polygon の受理と変換。
- 属性: `glVertexAttribPointer` / `glVertexAttribIPointer`（index 0）、normalized/integer フラグ、
  VAO 別の属性記録、`glPushClientAttrib` / `glPopClientAttrib` / `glPushAttrib` / `glPopAttrib` の復元。

### GL 表面
- display list: `glNewList` / `glEndList` / `glCallList` / `glCallLists` / `glListBase` /
  `glDeleteLists` / `glIsList`。
- pixelStore: UNPACK/PACK の記録・クエリ・アップロード変換への反映。
- buffer: storage / sub-data / copy / readback / map（DSA 含む）/ clear（零埋め）/ binding クエリ。
- texture: storage（DSA 含む）/ sub-image（DSA）/ parameter（f/iv/fv/Iiv/Iuiv、DSA）/
  border colour / level parameter（DSA）/ image readback のゼロ化。
- framebuffer: EXT/ARB 綴り、Named 形式のアタッチメント・状態・パラメータ、renderbuffer の extent。
- shader: info-log（ARB 含む）、active uniform/attrib、program binary、precision、resource 系、
  compile/link status、not-found ルックアップ（-1）。
- 同期: `glGetSynciv` は SIGNALED、クエリ結果は可視（1）。
- デバッグ: `glGetObjectLabel` / `glGetObjectPtrLabel` の空ラベル。

### シーン・検証
- メニュー/タイトル/パックメニュー、クリエイティブ画面、ツールチップ移動、モデル、空、雲、
  フォグ、発光 outline のシーンと参照比較。
- ルート検証器（`scripts/cpu-contract/transformer-route-verify.sh`）を CPU 契約に追加。
- KPI の control arm（同一 leg 内で candidate / Celeritas / 過去ビルドを交互計測）。

## 変更・改善（Changed / Improved）

### 描画忠実度
- タイトル画面・メニュー背景・パックメニューのアートをフレームへ（シーンで確認）。
- クリエイティブ画面のアイコン欠落（空の item plan キャッシュ）を修正。
- ツールチップ: 移動フレームで 1 フレーム 1 ツールチップ、mod FBO バインド中の取りこぼし/残像を修正。
- モデル/カスタム描画: ミラー供給の共通化、属性 0 の記述、VAO 別ポインタ、インデックス経路。
- 空/雲/フォグ/ライト/深度/ブレンド/シザー/ポリゴンオフセットの状態反映を整理。
- 半透明 terrain の背面 cull、combine 中の alpha test 維持、色付きガラスのちらつき修正。

### 状態・クエリ
- pname の取り違え（SKIP_PIXELS/ROWS、SPOT_CUTOFF、VIEWPORT_DIMS、SHADE_MODEL 等）を修正。
- 未初期化出力の一掃（sampler/renderbuffer/multisample/uniform/object label 等）。
- 固定幅書き込みのオーバーラン修正（light/material の成分数、boolean の 1 バイト）。
- バインディングクエリ（element/pixel/uniform/copy buffer、texture 1D/3D/cube、renderbuffer）。
- 能力値の整合（texture units、anisotropy、attachment/draw buffers、uniform vectors、stack depth）。

### 性能
- モデルリプレイ: 入力キャッシュ、値バージョン化、ライトペイロードの共有、行列/色/シザーの共有。
- グループ化: 状態キー、フォグ/シザー/ポリゴンオフセットのキャプチャ、ウィンドウ計測。
- クリア: 順序 flush のサイト計測、メイン FBO クリアのキュー搭載（既定 off、拒否 census 付き）。
- ホットパス: 単一参照化、プロパティ読みの定数化、アロケーション削減。
- フォント: バッチの行列保存をスクラッチ化、colour witness の絞り込み。

## 修正（Fixed）— 主なもの

- **起動/ビルド**: `RenderSection` の metrics アクセサ欠落、`@Inject` の位置 2 件、`@Shadow` の二重付与、
  Lombok の annotation processing 不動作。
- **実行時クラッシュ**: `glClearBufferSubData` のスロット、`glPushClientAttrib` の引数欠落、
  `glDrawElementsInstancedBaseInstance` のスロット、`nglGetShaderInfoLog` のスロット（GL20C ロード不能）。
- **テクスチャ**: ミラー未供給、PBO アップロード、DSA アップロード、サブイメージのパッチ、
  削除後の名前再利用、サンプラ推論（wrap/filter）。
- **FBO**: アタッチメント記録、EXT/ARB/Named 綴り、削除時のクリーンアップ、読み出しのルーティング。
- **状態**: raw の depth/alpha/lighting enable、push/pop、VAO 属性、ライト/フォグ/マテリアル、
  ピクセルストア、バッファバインディング。
- **クエリ**: 未初期化出力、pname 取り違え、幅の誤り、not-found の 0（-1 へ）。
- **描画**: インデックスのレイアウト/オフセット/再パック、クライアントメモリ、instance=1、
  ライン/ストリップ/ポリゴン、属性 0。
- **GUI**: メニュー背景、クリエイティブタブ、ツールチップ、HUD の色/深度。

## 性能（Performance）

### 対 Celeritas paired KPI（AMD RX 6400 / RADV NAVI24、1280×720、validation on、3 対）

| rep | Celtium p50 | Celeritas p50 | 比 | 過去ビルド比 |
|---|---|---|---|---|
| 1 | 2.742 ms | 2.332 ms | 1.176 | 0.985 |
| 2 | 2.869 ms | 2.413 ms | 1.189 | 1.063 |
| 3（負荷混入） | 3.620 ms | 2.311 ms | 1.566 | 1.380 |
| **中央値** | | | **1.189** | **1.063** |

- `goalCondition=NOT_MET`。clean な 2 rep は 1.176 / 1.189 で、過去ビルド（round 58）比は −1.5% / +6.3%。
- rep 3 は `finalLoadAverage` 0.96 → 3.98 の混入で、同型の汚染は round 63 でも観測済み。
- **フレーム内訳（出荷コード、AMD）**: frame 1322 µs = world 861 + gui 421 + hand 50。
  **85% は Celtium の即時経路**（受理 161 offer × 4024 ns = 648 µs + flush 392 + guiFlush 81）。
  単位は offer 160.8 / group 131.9 / 窓 23.4。
- **窓の起点は framebuffer bind**（`flushSiteCounts=[bind-framebuffer=792]`、`flushReasons` の 65%）。
  clear 起点という仮説は棄却済み。
- **残る構造レバー**: bind ごとの「frame image を実際にサンプルするか」census と不要 flush の削除、
  accept path の未計測区間（offPreflight〜offAppend の約 470 行）の bracket、
  bindless immediate textures、不透明・depth-write・非 blend 用の第 2 open group。
- **棄却済み**（再試行しない）: sticky pass 統合（2.85→11.47 ms）、font run の行列 bake（94→8 run）、
  clear 起点の flush 削減（窓/フレーム不変）、stateKey の format 要因（hit 21.9% のまま）。

## 既知の課題（Known issues）

- **FPS は Celeritas 比 1.189 で未達**。accept path とウィンドウが残。Intel の p99（1.048）も未解決。
- **メニュー/ツールチップ/クリエイティブタブ**はシーンで確認済みだが、テスター環境での再確認が必要。
- **未実装**: cube map / 3D texture / MSAA / compute / blit / copyImage / 一部の DSA /
  stencil（ModularUI の Stencil#reset は mask 0x400 で未実装）。
- **実機 leg は環境依存**: 検証ハーネスの Prism インスタンス構成に依存。配布 JAR は別途テスターで確認。
- **影/シェーダパック**: Demonica fork の addon として別成果物。core には取り込まない。

## インストール

1. Cleanroom Relauncher 構成（Cleanroom 0.7.12-alpha / LWJGL 3.4.3 / ゲーム JVM は Java 27）を用意。
2. `celtium-forge-mc1.12.2-0.2.0.jar` を `mods/` に置く。
3. 起動し、ワールドに入り、GUI/メニュー/クリエイティブ/ツールチップを確認。
4. 問題報告には `logs/latest.log`、`-Dceltium.vulkan.validation=true` の有無、GPU、シーン、JAR の sha256 を添付。
