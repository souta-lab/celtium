## Celtium 0.3.3

The final release of the current rendering engine. The build is main `85901595` (145 commits past the v0.3.2 tag). The gate is the full gate on the landing tree, all green (1,301 tests, 0 failures / 0 errors). The jar is `celtium-forge-mc1.12.2-0.3.3.jar`; its SHA-256 ships alongside it in the `.sha256` asset.

This release exists so that everyone still on the current engine gets the fixes that landed after 0.3.2 — above all the startup crash below. The rendering engine is being rewritten from scratch as a Vulkan-native architecture, and no further releases of this engine line are planned. Reports against 0.3.3 are still read, but fixes will land in the new engine rather than in a 0.3.4, unless a problem blocks startup entirely.

### Fixes

#### Crash during mod loading (access violation in the NVIDIA driver)

- The loading-screen flush reuses a cached `VkRenderPassBeginInfo`. That struct was allocated without being zeroed, so its `pNext` field held whatever the memory previously contained, and the driver could end up reading garbage at the very first flush — an access violation inside `nvoglv64.dll` during mod loading, on every launch, only with celtium present. This was reported against 0.3.2 on a GTX 1650 Ti and traced from the reporter's logs.
- The cached begin info is now zero-initialised at allocation and its `pNext` is written explicitly (`calloc` + explicit `pNext = 0`). The fix is in the exact call the crash was traced to.

#### BSL black wedge: the pow guard is now on by default

- 0.3.2 shipped a guard for fractional-constant-exponent `pow(base, exp)` in the mod GLSL conversion, off by default and unverified at the time. A verification leg on the shipped 0.3.2 jar has since measured the anti-sun cone NaN gone with the guard on and reproduced with it off, so the default is flipped: the guard is on unless `-Dceltium.vulkan.fractionalPowGuard=false` is set explicitly.

### The GlStub removal (GLSM migration complete)

- The OpenGL stub layer is deleted. GL state handling now lives entirely in the GLSM state machine; there is no stub path left to fall back to.
- This landed on the §6 evidence pack: same-jar A/B presentation identity, counter equivalence between the old and new paths, a real-modpack check, and the frame-time distribution shape (P50/P95/P99), on top of the full gate above.

### Other

- Terrain pipelines now share one descriptor set per sampler group via dynamic offsets, removing a per-region set accumulation cliff (item 678 B3). Internal instruments, refactors and contract-check updates also landed. None of these claims a performance advantage.
