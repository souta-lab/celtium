# Celtium 0.2.1 — faster than Celeritas in a real modpack

*Released 2026-11-06 · tag [`v0.2.1`](https://github.com/souta-lab/celtium/releases/tag/v0.2.1) · previous [`v0.2.0`](https://github.com/souta-lab/celtium/releases/tag/v0.2.0)*

*English: [0.2.1 release notes (English)](https://github.com/souta-lab/celtium/blob/main/docs/releases/0.2.1-en.md)*

0.2.0 からの **189 commits**。実modpack（Supersymmetry 0.2.0.2、188 mods）で **Celeritas を p50/p95 で上回り**、
有名modpack 7本が AMD/Intel で world に到達（validation 0）。mod 自前の GLSL program の native 実行、
shaderc natives の同梱、描画・同期の修正、巨大クラスの分割を含みます。

> **FPS 目標はまだ未達**: p99 はほぼ同等（AMD 0.993 / Intel 0.993）だが、各GPU 1対が p99 で 1 を超えるため
> `goalCondition=NOT_MET`。p50/p95 の優位は再現済み。

---

## ハイライト

- **実modpackで Celeritas を上回った**。Supersymmetry 0.2.0.2（188 mods、qmagnet、1280×720、validation off、
  3対×240 s）:
  - AMD RX 6400: p50 **0.976** / p95 **0.935** / p99 **0.993**（Celtium/Celeritas の frame time 比）
  - Intel UHD 630: p50 **0.940** / p95 **0.970** / p99 **0.993**
  - 2回目のAMD run（`l28kpi-amd`）は p50 0.918 / p95 0.905 / p99 0.991。
- **有名modpackの互換拡大**: SkyFactory 4 4.2.4、All the Mods 3 6.1.1、RLCraft 2.9.3、SevTech: Ages 3.2.3、
  Nomifactory CEu 1.7.7、Project Ozone 3 3.4.11F、E2E-E 1.87.3（≈430 mods）が AMD/Intel で world 到達・validation 0。
- **mod 自前 GLSL の native 実行**（opt-in `-Dceltium.vulkan.modPrograms=true`）。GTCEu bloom を native パスで実行し
  validation 0。既定は program ごとに拒否・計数（安全側）。LWJGL の **shaderc natives（linux/windows x64）**を同梱。
- **描画・同期の修正**: raw framebuffer bind が main target に描く、mod particle layout の PARTICLE への再パック、
  SkyFactory 4 の空が平坦な青になる不具合、atlas の mip level の VUID-09600、acquire semaphore の再利用、
  renderer 起動失敗時の crash report。
- **コード整理**: `VulkanTerrainGpuBackend` 22,576 → 21,038 行。IndirectImmediateRuns / ModPrograms /
  FrameStatsReport / GroupLighting / GroupChange / PixelSignatures / HighlightProbe を分離。
- **検証ハーネス**: `pack_verify.py`（ログ分類と Celeritas 画像比較）、modpack preset（sf4/atm3/rlcraft/sevtech/nomi/po3）、
  `modpack-reverify.sh`。

## 性能（Performance）

**測定環境**: Supersymmetry 0.2.0.2（GregTech CEu ベース、188 mods）、Cleanroom Relauncher、save `qmagnet`、
pose `x=217.5 y=48 z=217.5 yaw=180 pitch=10`、render distance 12、GUI scale 3、1280×720、vsync off、validation off。
build r107（`5ff004c26`）、3対×240 s/GPU（`l27kpi-amd` / `l27kpi-intel`、2026-11-06）。

| GPU | | Celtium | Celeritas 2.5.0-dev | 比（pair中央値） |
|---|---|---|---|---|
| AMD RX 6400 | p50 | **427 FPS** | 407 FPS | **0.976** |
| | p95 | **227 FPS** | 214 FPS | **0.935** |
| | p99 | 174 FPS | 179 FPS | 0.993 |
| Intel UHD 630 | p50 | **296 FPS** | 273 FPS | **0.940** |
| | p95 | **167 FPS** | 159 FPS | **0.970** |
| | p99 | 139 FPS | 138 FPS | 0.993 |

- 比は frame time の Celtium/Celeritas（**小さいほど良い**）。FPS は参考値で、pair中央値の中央値。
- p99 は AMD pair 2（1.121）と Intel pair 2（1.081）が 1 を超え、`goalCondition=NOT_MET`。
  6 AMD pair の p99 は 0.924 / 1.121 / 0.993 / 0.991 / 0.942 / 1.058（中央値 0.99）。
- 0.2.0 リリース時点は同packで p50 約16%負け。main でここまで回復。
- 証拠: [animated-sprite-uploads-2026-11-05.md](<../evidence/animated-sprite-uploads-2026-11-05.md>)。

## 追加・変更（Added / Changed）

- **mod program**: `glUseProgram` 系のルート、program ごとの拒否・計数、opt-in の native 実行、shaderc natives 同梱。
- **harness**: `pack_verify.py`、`modpack-reverify.sh`、pack preset（sf4/atm3/rlcraft/sevtech/nomi/po3/e2ee）、
  `CELTIUM_E2E_PACK`、`CELTIUM_WARM_WINDOW`、leg ごとの pack copy 解放。
- **fixture**: world switch の title screen 対応、getter 経由の counter 読み、presented counter の再起動、
  `keepEntities`、`cameraY`、`worldType`。
- **診断**: `CELTIUM_RECORD`（重複排除）、`CELTIUM_PRESENT` heartbeat、`CELTIUM_PROGRAM_BOUND`。
- **コード**: 巨大クラス分割、孤立 javadoc 整理、未使用 switch/分岐の削除。

## 修正（Fixed）

- raw framebuffer bind が main target に描く（ATM3 の一人称手）。
- mod particle layout を PARTICLE に再パック（FBP 粒子の拒否）。
- SkyFactory 4 の空が平坦な青になる（非ITEM群の照明payloadがfogを失う）。
- atlas の mip level 書き込み後の layout（VUID-vkCmdDraw-None-09600）。
- acquire semaphore の再利用（image 再取得後）。
- renderer 起動失敗時に crash report を出す（Loading terrain で止まらない）。
- mod program pipeline のキー（参照）と world teardown での解放。
- indirect run の group 合流条件（pipeline/descriptor/buffers/alpha）。
- 空の arena mesh の stride、transformed vertex の一括コピー、window の index 上限 32768。
- 描画前の published-output layout 検査、mod pass の入力可視性、window prefix の target。

## 既知の課題（Known issues）

- **p99 の pair 外れ**: AMD pair 2 / Intel pair 2。`goalCondition=NOT_MET`。
- **modpack の完全検証**: SF4/ATM3/RLCraft/SevTech/Nomifactory は validation 0 のみで、ログ全文と
  Celeritas 画像比較が pending。
- **描画欠陥**: 葉の暗化（mipmap）、ATM3 の空グラデーション、RLCraft の ordering flush / destroyed mesh、
  GTCEu bloom は既定 off（`-Dceltium.vulkan.modPrograms=true` で有効）。
- **未実装**: cube map / 3D texture / MSAA / compute / blit / copyImage / 一部 DSA / stencil。
- **影・shaderpack**: Demonica fork の別 addon。
