# Celtium 0.2.1 — faster than Celeritas in a real modpack

*Released 2026-11-06 · tag [`v0.2.1`](https://github.com/souta-lab/celtium/releases/tag/v0.2.1) · previous [`v0.2.0`](https://github.com/souta-lab/celtium/releases/tag/v0.2.0)*

**189 commits** since 0.2.0. In a real modpack (Supersymmetry 0.2.0.2, 188 mods) Celtium now beats Celeritas at
p50/p95, seven well-known packs reach the world on AMD and Intel with zero validation errors, mod GLSL programs can run
natively, shaderc natives ship with the jar, and the rendering/synchronisation fixes and the large-class split are in.

> **The FPS goal is still not met**: p99 is at parity (AMD 0.993 / Intel 0.993), but one pair per GPU crosses 1 at p99,
> so `goalCondition=NOT_MET`. The p50/p95 lead is reproduced.

---

## Highlights

- **Faster than Celeritas in a real modpack.** Supersymmetry 0.2.0.2 (188 mods, qmagnet, 1280×720, validation off,
  3 pairs × 240 s):
  - AMD RX 6400: p50 **0.976** / p95 **0.935** / p99 **0.993** (Celtium/Celeritas frame-time ratio)
  - Intel UHD 630: p50 **0.940** / p95 **0.970** / p99 **0.993**
  - A second AMD run (`l28kpi-amd`) measured p50 0.918 / p95 0.905 / p99 0.991.
- **More modpacks**: SkyFactory 4 4.2.4, All the Mods 3 6.1.1, RLCraft 2.9.3, SevTech: Ages 3.2.3,
  Nomifactory CEu 1.7.7, Project Ozone 3 3.4.11F and E2E-E 1.87.3 (≈430 mods) reach the world on AMD and Intel with
  zero validation errors.
- **Native execution of a mod's own GLSL** (opt-in `-Dceltium.vulkan.modPrograms=true`). GTCEu's bloom runs as a
  native pass with zero validation errors; the default refuses and counts each program (safe side). LWJGL's
  **shaderc natives (linux/windows x64)** ship with the jar.
- **Rendering and synchronisation fixes**: a raw framebuffer bind draws into the main target, mod particle layouts are
  repacked into PARTICLE, SkyFactory 4's flat blue sky, the atlas mip-level VUID-09600, acquire-semaphore reuse, and a
  crash report when the renderer cannot start.
- **Code cleanup**: `VulkanTerrainGpuBackend` 22,576 → 21,038 lines; IndirectImmediateRuns / ModPrograms /
  FrameStatsReport / GroupLighting / GroupChange / PixelSignatures / HighlightProbe split out.
- **Verification harness**: `pack_verify.py` (log classification and Celeritas picture diff), modpack presets
  (sf4/atm3/rlcraft/sevtech/nomi/po3) and `modpack-reverify.sh`.

## Performance

**Setup**: Supersymmetry 0.2.0.2 (GregTech CEu based, 188 mods), Cleanroom Relauncher, save `qmagnet`, pose
`x=217.5 y=48 z=217.5 yaw=180 pitch=10`, render distance 12, GUI scale 3, 1280×720, vsync off, validation off.
Build r107 (`5ff004c26`), 3 pairs × 240 s per GPU (`l27kpi-amd` / `l27kpi-intel`, 2026-11-06).

| GPU | | Celtium | Celeritas 2.5.0-dev | ratio (pair median) |
|---|---|---|---|---|
| AMD RX 6400 | p50 | **427 FPS** | 407 FPS | **0.976** |
| | p95 | **227 FPS** | 214 FPS | **0.935** |
| | p99 | 174 FPS | 179 FPS | 0.993 |
| Intel UHD 630 | p50 | **296 FPS** | 273 FPS | **0.940** |
| | p95 | **167 FPS** | 159 FPS | **0.970** |
| | p99 | 139 FPS | 138 FPS | 0.993 |

- The ratio is frame time Celtium/Celeritas (**lower is better**). FPS is the median of pair medians, for reference.
- p99: AMD pair 2 (1.121) and Intel pair 2 (1.081) cross 1, so `goalCondition=NOT_MET`. The six AMD pairs' p99 ratios
  are 0.924 / 1.121 / 0.993 / 0.991 / 0.942 / 1.058 (median 0.99).
- At the 0.2.0 release the same pack was about 16% behind at p50; `main` recovered the gap.
- Evidence: [animated-sprite-uploads-2026-11-05.md](<../evidence/animated-sprite-uploads-2026-11-05.md>).

## Added / Changed

- **Mod programs**: `glUseProgram` routes, per-program refusal and counting, opt-in native execution, shaderc natives.
- **Harness**: `pack_verify.py`, `modpack-reverify.sh`, pack presets (sf4/atm3/rlcraft/sevtech/nomi/po3/e2ee),
  `CELTIUM_E2E_PACK`, `CELTIUM_WARM_WINDOW`, per-leg pack-copy release.
- **Fixture**: world-switch title screen, counter reads through getters, presented-counter restart, `keepEntities`,
  `cameraY`, `worldType`.
- **Diagnostics**: `CELTIUM_RECORD` (deduplicated), `CELTIUM_PRESENT` heartbeat, `CELTIUM_PROGRAM_BOUND`.
- **Code**: large-class split, orphaned javadoc cleanup, unused switches and branches removed.

## Fixed

- A raw framebuffer bind draws into the main target (ATM3's first-person hand).
- Mod particle layouts are repacked into PARTICLE instead of refused (FBP particles).
- SkyFactory 4's sky no longer turns into a flat blue band (non-ITEM groups lost fog in the lighting payload).
- The atlas mip-level write returns to SHADER_READ_ONLY (VUID-vkCmdDraw-None-09600).
- Acquire semaphores are reused only after the image is acquired again.
- A renderer that cannot start ends the game with a crash report instead of "Loading terrain".
- Mod program pipelines are keyed by reference and released at world teardown.
- Indirect runs join a group only when pipeline, descriptor, buffers and alpha match.
- Empty arena mesh stride, transformed-vertex bulk copy, window index limit 32768.
- Published-output layout check, mod pass input visibility, window prefix target.

## Known issues

- **p99 pair excursions**: AMD pair 2 / Intel pair 2. `goalCondition=NOT_MET`.
- **Full modpack verification**: SF4/ATM3/RLCraft/SevTech/Nomifactory have validation 0 only; full logs and
  Celeritas picture comparisons are pending.
- **Rendering defects**: leaf darkening (mipmap), ATM3's sky gradient, RLCraft's ordering flush / destroyed mesh,
  GTCEu bloom off by default (`-Dceltium.vulkan.modPrograms=true` enables it).
- **Not implemented**: cube maps / 3D textures / MSAA / compute / blit / copyImage / some DSA / stencil.
- **Shadows/shader packs**: a separate addon built from the Demonica fork.

## Install

1. Cleanroom Relauncher (Cleanroom 0.7.12-alpha or later in the 0.7 line, 0.7.14 verified / LWJGL 3.4.3 / game JVM
   Java 25+).
2. Put `celtium-forge-mc1.12.2-0.2.1.jar` into `mods/` (do not install Celeritas).
3. Start the game and check the world, GUI and modpacks.
4. For bug reports, attach `logs/latest.log`, the GPU, the pack/version and the JAR sha256.
