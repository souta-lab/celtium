# Celtium 0.1.3-alpha-rc.2 — visibility correctness test build

**Experimental test release.** Builds on the Windows startup/surface fixes from v0.1.3-alpha-rc.1. This targets an *unconfirmed* cause of brief disappearing terrain sections during camera flight on Windows.

## Changes

- The async chunk visibility system no longer treats small changes in the view-projection matrix (previous tolerance 0.002) as an identical view. It now compares the exact captured search view, including position movement within a block and the frustum camera offset.
- Mark the graph dirty when the frustum/search view has changed even if the entity camera state is unchanged (for example, modified camera transforms).
- Before rendering terrain, join an in-flight search whenever the published section lists were produced for a different camera view.
- Add GPU-independent tests proving that tiny rotations, within-block motion, and frustum offset changes prevent stale-list reuse.

## External report and limits

- New tester report: https://mclo.gs/xR4EztZ — Windows RTX 3070, Cleanroom 0.7.14, Vulkan surface/presentation initialized successfully; chunk sections appear briefly missing while flying.
- Tracking issue: https://github.com/souta-lab/celtium/issues/411
- No GPU validation errors in this log. This does **not** rule out races in mesh rebuilds or chunk stream availability. The reported test world references thousands of missing mod registry entries and is not an ideal rendering control.
- **Windows runtime results and flight performance have not yet been measured on this candidate.** Exact view comparisons can increase search joins under constant camera movement.

## Recommended tester A/B

Use a **fresh vanilla world** in a separate test instance (do not overwrite the original world with missing-mod mappings). Keep only one Celtium version installed. Compare rc.1 vs rc.2 using the same high-speed flight route, especially when making small turns.
If flicker persists, try `-Dceltium.terrain.asyncOcclusion=NONE` on rc.2, then send both logs and a short clip with F3 enabled. Report whether chunks disappear entirely or merely take time to fill in.

Build verification: `./gradlew -p build-1122 :common:test :celtium-vulkan:test :forge122:packageJar`. GPU-independent tests pass on the Linux build host.
