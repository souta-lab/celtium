## Celtium 0.3.2

0.3.1 の hotfix。クラッシュ修正が中心で、新機能はない。対象ビルドは main `692821cd0`（v0.3.1 タグ `33989b027` から 69 commits）。ゲートはリリースツリーでの PC フルゲート全緑（1,362 tests、failures 0 / errors 0、skipped 1 は既知）。jar は `celtium-forge-mc1.12.2-0.3.2.jar`、sha256 `f63ea89ccb56dc7191d0750da137b2868fcb602fb3a7e5feb17202bac71f03d3`。

### 修正

#### flush 境界のクラッシュ（descriptor set の use-after-free）

- 即時描画グループがキューに積まれた後、そのテクスチャ用 descriptor set がキャッシュ（上限 64 キー）から追い出されると、解放済みの set が flush 時に bind され、ドライバ内でクラッシュし得た。Texture 家系で穴をコード原典の歩行により確認し、flush 時に「準備済みの set がまだキャッシュにあるか」を照合して、無ければ再構築するよう直した（main `8592baec4`）。
- 同じ穴が Item / Block / Particle の兄弟 3 家系にもあることを監査で確認し、同じ照合＋再構築を 3 家系すべてに入れた（main `d8acd0657`）。Item 家系は上限 64 を Texture 家系と共有しており、日常的に到達し得る経路だった。
- **正直な留保: この修正は実機 leg で「追い出しが起きて再構築カウンタが発火する」形の実証は取れていない。** 検証 leg では追い出しの interleave が発生せず、カウンタは 0 のままだった。修正の根拠は、コードレベルの穴の証明、契約テスト（EvictedDescriptorRebuildTest 3/3、SiblingEvictedDescriptorRebuildTest 4/4）、および統合ツリーのフルゲート全緑である。「再現条件で発火して塞いだ」とは主張しない。

#### 起動スプラッシュの表示ずれ（窓問題 2）

- 起動直後、読み込み画面の描画がウィンドウ実寸でなく要求サイズ（1280x720）に凍結され、右側が切れて表示され、途中で直る問題。`presentLoadingProgress` が swapchain の実寸にレイアウト寸法を合わせるよう直した（main `de6375a54`）。
- 留保: 対象テストは全緑だが、実機での検証 leg はまだ実施していない。着地をもって問題が消えたとは主張しない。

#### BSL の黒い楔への pow ガード（既定 off）

- シェーダーパック BSL で、太陽と反対側に黒い楔が出る問題への対策として、mod GLSL 変換に分数定数指数の `pow(base, exp)` ガードを追加した（main `529ccc3da`）。根因は、パックの体積光パス内部で生じる NaN が黒に変換されることまで特定済み。
- **このガードは既定 off** で、有効化は `-Dceltium.vulkan.fractionalPowGuard` を付けた場合のみ。
- **BSL が直ったとは書かない。** 円錐内の NaN が消えたことを測る検証 leg はまだ実施しておらず、解消の可否は未確認のままである。

#### Twilight Forest のシェーダーリンク失敗

- Twilight Forest のシェーダーが `gl_NormalScale` のためリンクに失敗していた（8 件中 7 件が同原因）。mod GLSL 変換で `celtium_NormalScale` uniform へ下げるよう直した（main `96e8ee123`）。
- 留保: 受入 leg（コンパイル census の再測）はまだ実施していない。

#### その他

- bloom チェーンの経路修正（main `e6da4ad83`）: 地形パスの束縛先への経路は発火を確認したが、**ハロー帯は提示画像へ依然届いておらず、bloom が直ったとは言えない**。問題はさらに下流にあり調査継続中。
- 内部の計器・リファクタ・性能実験の着地を含む（測定で差が出なかった明示的確保の実験、C1 ±Y shelves の撤去、TickTimings のラッチ修正、死宣言フィールドの除去ほか）。いずれも性能の優位を主張するものではない。

### 既知の残件（この版では直っていない）

- **項目 699**: `IndirectImmediateRuns` が同一 flush 内で後続グループの再構築を跨いで descriptor を保持する経路が残っている。上記 flush 修正の対象外で、4 家系すべてに共通する既存の残件として未修正。
- BSL の黒い楔そのもの（上記のとおり、ガードは既定 off・検証未実施）。
- VUID-09600 は解消していない（従来どおり残存）。
