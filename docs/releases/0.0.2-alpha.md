# Celtium 0.0.2-alpha — release record

**Status: prepared, not yet published.** 0.0.1-alpha is the published baseline; this records what has landed
since and what a 0.0.2-alpha build would contain, so the version question has an answer with evidence rather
than a guess.

- **Baseline**: `v0.0.1-alpha` (published 2026-10-12, artifact `celtium-0.0.1-alpha-mc1.12.2.jar`, SHA-256
  `7db3063a95918a3acee2287288683b9887c70ab9ba075a1b729b4e73a901d415`). Its tag was rewritten by the history
  rewrite and now points at `4ffc786aaf9c06c5c239feffc115101b4329cdc5`; see `0.0.1-alpha.md`.
- **Distance**: **17 commits** from the tag to `dd67ed93a` at the time of writing.
- **Development version is unchanged** (`2.5.12-celtium.0.1.0-dev.1`): 0.0.1 was packaged with
  `-Pceltium_release_version=0.0.1-alpha` precisely so that publishing did not move the development version, and
  0.0.2 should be built the same way — `-Pceltium_release_version=0.0.2-alpha`.

## What is explicitly not in a 0.0.2

- **No Intel acceptance of this build.** The 0.0.1 record says the same and it is still true.
- **No whole-game, mod-cohort or performance acceptance.** The mod cohort is one mod deep (HEI 4.31.2 loads and
  reaches the world; its list, search and tooltips are not yet accepted), and the performance work is measured on
  the user's own profile rather than on a release build.
- **BH-09 is fixed but not accepted**, and **nine BH findings remain open** (BH-14, 17, 18, 20, 21, 24, 26, 33, 35).
- **The GL bridge path deadlocks on the first world frame on this machine**, deterministically, in three baseline
  legs of the drain work (`docs/perf-render-thread-drains-handoff.md`). This release is **not** exposed to it because
  GL-less is the default; but it means `-Dceltium.vulkan.glless=false` is **not a working comparison arm** on this
  machine until that is fixed, and any acceptance that needs the bridge must say so.
- **The residual p99 spike (~326 ms) is unattributed**, and the user profile's ~246 ms/frame of unnamed
  `gameRenderer` residual is still unexplained. The largest single item in that profile is `gui` self time
  (5,359 ms of a 20 s capture, 26.8 % of the frame) and it is a per-frame constant, not a spike source.
- **Loading screen, panorama and GUI text darkening** are open: the first is missing geometry, the second has a
  named owner (the splash texture's mirror), and the third does not reproduce in the current tree.

## Version decision

`0.0.2-alpha` is the right next number: the published baseline is 0.0.1-alpha, the changes since are additive
and observable (a default flip, a font path that removes vanilla's per-glyph body, four resolved findings), and
nothing in them claims the completion conditions the objective sets. Calling it 0.1.0 would imply the
shaderless body is accepted, which the list above says it is not.
