# Celtium 0.1.4-alpha-rc.18 — consecutive model runs share one indirect range

A world window's model runs were one indirect command range each. A run that continues the previous
run in the same command/vertex/index buffers, starting exactly where the previous run's commands
ended, with the same pipeline, texture set, viewport hash, projection and fog, now extends the
previous run's command count. The merged draw is issued when the sequence ends - before any
non-model group draws, at the end of the segment, or when a run fails a merge condition - and a run
that cannot merge flushes the pending one first, so nothing is dropped.

Susy world leg: warm P50 2.48 ms against 2.54 for rc.17's bind/push skips alone. Canonical plain
gate PASSED with the floors enforced and the presented image judged.
