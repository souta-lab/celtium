# Celtium 0.1.4-alpha-rc.17 — fewer commands per model run

A world frame is about a hundred model runs, each one multi-draw-indirect over the bindless texture
array. Each run used to bind pipeline, descriptor set, push its projection/fog block, bind vertex
and index buffers and draw. Two of those are now conditional on the previous draw being the same
kind of run: the pipeline and set binds (rc.16) and the push block when its bytes are identical.

The invalidation is the group loop itself - any group without a modelRun clears the cache - and
the full path always pushes and records its block, so the cached path can never leave stale state.

Canonical plain gate: PASSED with floors enforced and the presented image judged.
