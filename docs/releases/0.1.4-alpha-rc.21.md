# Celtium 0.1.4-alpha-rc.21 — the atlas upload reports both extents and every recreate

rc.20 added `CELTIUM_UPLOAD_EXTENT` (the copy it is about to make, beside the image it writes into). The
black-screen crash copies through a path that reports before it, though: the announcement path (`fromImage`)
and the image recreate. Both are named now.

- `CELTIUM_ANNOUNCE_EXTENT id=.. announced=WxH image=WxH rebuild=..` - what the announcement carries against
  the image the registry holds for that name, before any transfer.
- `CELTIUM_MIRROR_RECREATE texel=.. from=WxH to=WxH levels=..` - every image recreate, with the level count.

A run that loses the device on the 4096x4224 font atlas can now be read as: which extent was announced, what
the image was, whether it was rebuilt, and what the copy then did - without the validation layer.

Also carries rc.20 (the extent diagnostic and the refusal of out-of-image copies) and rc.19.
