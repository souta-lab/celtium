# Celtium 0.0.18-alpha

対象: **Minecraft 1.12.2 / CleanroomMC 0.7.11-alpha / SDL3・LWJGL 3.4.3 / Java 27**。
0.6.13-alpha（GLFW / LWJGL 3.4.1）は起動時に明示拒否します（SDL3バインディング不在のため）。

0.0.17 は配布していません（開発版の番号を 0.0.18 に上げたため、0.0.16 の次がこの版です）。

## 互換性

- **Xaero's Minimap**: 起動時クラッシュ・世界が真っ暗になる・地図の位置ずれ・タイルが透ける問題を修正
  （mod 独自 framebuffer の扱い、PBO offset 0 と `UNSIGNED_INT_8_8_8_8` のタイル転送、framebuffer 間のサンプリング）。
- **発光（glowing）アウトライン**: vanilla の framebuffer 合成を native に描画し、表示されるように。
- **vanilla の post shader**（観戦時の creeper / spider 等）が GL なしの経路で読み込み・実行されるように。

## 描画の修正

- **色付きガラスのちらつき**: 解放した arena 範囲を、まだ読んでいる可能性のあるフレームが終わるまで保持するよう修正。
- 半透明の再ソート後のちらつき（upload copy の順序）を修正。
- エンドポータルの星空（texgen）を native に描画。
- ダメージ時の赤フラッシュでアルファテストが外れる問題を修正。
- **ロード画面**: Forge 自身のロード画面（ロゴ・メモリ・進捗）を native に描画し、ロードスレッドを止めないように。

## 性能

- Intel でもフレーム単位でまとめて submit（UHD 630 で 1.6–1.8 倍速）。
- Xaero 導入時に mod framebuffer を毎 pass 作り直していた問題を修正（Intel 7.3 → 3.0 ms）。
- **F3+T**: リソースパックが変わっていなければフォントアトラスを再生成しない。
- エンドポータル・ゲートウェイを 1 layer 1 draw にまとめる、model display list を instance 描画、pipeline cache の永続化など。

**現状の数値（正直に）**: AMD RX 6400・Xaero 入りの instance で、warm p50 は Celeritas 2.5.0-dev の約 1.31 倍遅い
（Xaero なしでは同等 0.99 倍）。Intel も Xaero 入りでは遅い。Celeritas を下回るのはまだ目標です。

## 既知の問題

- Xaero 入りでは Celeritas より遅い（上記）。
- シェーダーパックは本体では非対応（Demonica fork 側で進行中）。
