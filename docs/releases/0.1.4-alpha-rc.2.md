# Celtium 0.1.4-alpha-rc.2 — Immersive Railroading draw fix

Follow-up to 0.1.4-alpha-rc.1. This build fixes the eight draw-array refusals a SuperSymmetry run
reported for Immersive Railroading's item-sprite capture, and fixes a JVM crash the first version of
that fix introduced. Everything else is unchanged from rc.1.

## Changes

- **Identity projection for off-target draws**: the projection guard refused every draw whose mirrored
  projection was the identity, because the world scene would be drawn with the wrong transform. A mod's
  off-target sprite capture is the other case - Immersive Railroading draws unit-sized models into a
  128x128 framebuffer at mod-reload time, before any perspective exists, and expects clip space. The
  guard now asks whether the draw framebuffer is the window's own image (target registry identity against
  the main and game identities) and keeps refusing the world case only.
- **Split-array repack across VBOs**: the stride-48 repack read the split pointers as client addresses.
  The measured draws are VBO-backed (offsets into the bound buffer's mirror), so the repack copied from
  address zero and took the JVM down with `SIGSEGV` in `jbyte_disjoint_arraycopy`. The layout is now
  accepted only after the pointers are validated for the draw in hand - client memory by readable mapping,
  VBO by mirror capacity - and the repack bases are armed from that same decision.

## Measured state

Linux / AMD RX 6400, SuperSymmetry, Cleanroom Relauncher 1.3.0, GL-less.

- Menu run: draw-array refusals **8 -> 0**, `glDrawArrays` drawn 0 -> 64, two
  `CELTIUM_CLIENT_ARRAY_REPACK` lines (89241 and 46776 vertices), no validation errors, no crash.
- World run (qmagnet, presented image captured): the repack also runs, the remaining draw-array refusal
  is one, a different mod's stride-24 client-array layout; 4 `PATCH_REJECTED`, 1 `COMPOSITE_REFUSED`,
  3 `CAPTURE_MISS` remain as in rc.1. No validation errors, no device lost, picture renders correctly.

The performance relation to Celeritas is unchanged from rc.1 (world-only warm P50 1.48x SuperSymmetry,
2.65x ATM3) and is still not a stated goal of this build.
