# Celtium 0.1.4-alpha-rc.19 — model runs stop re-binding anything that repeats

Three command savings for model runs, each conditional on the previous draw in the segment being a
run with the same state: the pipeline and descriptor set (rc.16), the projection/fog push when its
bytes match, and now the vertex/index buffer pair. The full path always binds, pushes and records,
and the group loop clears the caches for every group whose modelRun is null, so no other draw can
leave them stale.

Also carries the merge of consecutive model runs into one indirect range when their commands
continue with the same state, and the counters that report the merge rate.

Canonical plain gate: PASSED with the floors enforced and the presented image judged.
