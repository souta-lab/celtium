# 面の cull は「enable」ではなく「面」で決まる: ミラーは正しく、pipeline が読んでいなかった（2026-11-03, round 12）

Owner: **custom rendering fidelity**（mod の `glCullFace`/`glFrontFace`）。Unit: 「GL が cull する面と、Celtium が
cull する面が同じ」。

## 症状

状態モデルは cull の **enable** だけを持ち、全 pipeline が GL の既定ペア（cull back・front face は
counter-clockwise）を焼き込んでいた。GL の既定は `GL_BACK`/`GL_CCW` なので既定状態の絵は正しい。しかし
`glCullFace(GL_FRONT)`（裏返ったモデル・内側から見る面を描くときの形）や `glFrontFace(GL_CW)` を選ぶ mod は
**逆の面を cull** され、geometry が消える。しかも同じ frame の `glGetIntegerv(GL_CULL_FACE_MODE)` は
`1028`（`GL_FRONT`）と正しく答えていた: **ミラーは忠実で、誰も読んでいなかった**。

## 根因

* `VulkanTerrainGpuBackend` の state 配列 `state[5]` は cull の真偽値1個。signature も
  `SIGNATURE_CULL`（enable）だけ。
* `VulkanImmediate*Pipeline` / `VulkanModelInstances` は `boolean cull` を取り、
  `.cullMode(BACK /* or NONE */)` と `.frontFace(VK_FRONT_FACE_CLOCKWISE)` を固定で焼いていた。
* `NativeRasterState.cullFace(int)` / `frontFace(int)` は値は書くが **version を上げていなかった**。この2つだけが
  version を上げない raster setter で、model replay の `versionsProven` 経路は「state は変わっていない」と判断して
  前回の tuple（＝前回の cull mode）を再利用し得た。

## 修正

* `VulkanCullState`: `(enable, face, winding)` を1個の int に符号化する。下位2bit が面
  （`NONE=0`/`BACK=1`/`FRONT=2`/`FRONT_AND_BACK=3`）、bit2 が `glFrontFace(GL_CW)`。
  GL の既定ペアは **1** のままなので、既存 pipeline key・既存の絵は不変。Vulkan 側は
  `VK_CULL_MODE_FRONT_BIT`/`FRONT_AND_BACK` と `VK_FRONT_FACE_COUNTER_CLOCKWISE` に写す
  （framebuffer の Y が反転するので GL の CCW は Vulkan の CW。ここでは「GL が front と呼ぶ面」を
  `VK_CULL_MODE_FRONT_BIT` に写すので、面の意味は一致する）。
* signature に `SIGNATURE_CULL_FACE` / `SIGNATURE_FRONT_FACE` を追加（`SIGNATURE=21`）、
  `celtium$stateFromSignature` が `state[5]` に符号化する。cull が無効なら面と winding は捨てる
  （使っていない状態で pipeline を分けない）。
* 5つの immediate pipeline と `VulkanModelInstances` の `cull` を int に変え、raster state を
  `VulkanCullState.vkCullMode/vkFrontFace` から作る。record-reading twin（間接描画）にも同じ符号化を渡す。
* `NativeRasterState.cullFace/frontFace` が version を上げる。`VulkanGlState` に `frontFace()`/`cullState()`。
* 診断行の `cull=` は `back/ccw(1)` の形で符号化値込みにした。

## 未対応（次の候補）

* フォント batch（`FontBatch`）と terrain pipeline は依然として固定の cull 状態。terrain の面 cull は
  block-face 単位の設計なので対象外、font は `GL_FRONT` 中の文字描画のみ。
* `glGetBooleani_v`/`glGetIntegeri_v` の indexed query（1バイト/汎用の0のまま）。
* `GL_LIGHTING_BIT` など attribute stack の未対応集団。
